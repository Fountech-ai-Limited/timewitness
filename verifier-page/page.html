Check a receipt

A TimeWitness receipt says UTC was somewhere in an interval when something happened, and carries signed evidence from parties who have never heard of us. This page checks one.

Nothing leaves this page. The receipt and the file it stamps are read from your own disk and checked here. There is no request of any kind, no account, and nothing of ours is involved: save this page, unplug the machine, and it gives the same answer. That is the point of it. A verifier only we can run is not evidence.

It runs the same checking code as the command line tool, compiled to WebAssembly, so the two cannot drift apart and say different things about the same receipt.

    Three roles and none of them does another's job. An authenticated corridor makes the bound checkable by a stranger and does not tighten it. A freshness beacon says not earlier. A final witness says not later. The agent's own bound is a claim and is not on this list.
